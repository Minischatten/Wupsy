# Wupsy 0.7.0 (Build 3)

Vorbereitungsnotizen zur [stabilen Veröffentlichung Wupsy 0.7.0](https://github.com/Minischatten/Wupsy/releases/tag/v0.7.0).

## English

- The editor supports music notes on straight, elliptical and editable Bézier
  paths. Notes can move in front of or behind an image layer and can grow or
  shrink along an open path.
- Add an animated Fog layer between image layers. Choose Ground Fog or
  Atmospheric Fog and adjust density, softness, structure scale, height,
  color, drift direction and speed.
- Rename layers directly in the editor and adjust image layer opacity.
  Smooth Anchor aligns the selected Bézier anchor’s handles.
- The menu bar menu is more compact. Settings bring together launch at login,
  updates, interface size, library actions and playback.
- Drop files anywhere in the wallpaper library to import them. Press Return to
  rename the selected wallpaper.
- Wupsy prepares eligible image and scene transitions and keeps the previous
  wallpaper if preparation fails.

The build targets Apple silicon (ARM64) with macOS 14 as its minimum deployment
target. The Music Notes guide walks through the editor features with examples.
[Music Notes guide](../anleitungen/MUSIC-NOTES.md)

## Deutsch

- Der Editor bietet Musiknoten auf geraden, elliptischen und frei bearbeitbaren
  Bézierpfaden. Noten können relativ zu einer Bildebene die Tiefe wechseln
  und entlang offener Pfade perspektivisch kleiner oder größer werden.
- Füge animierten Nebel als eigene Ebene zwischen Bildebenen ein. Wähle
  Bodennebel oder atmosphärischen Nebel und passe Dichte, Weichheit,
  Strukturgröße, Höhe, Farbe, Bewegungsrichtung und Geschwindigkeit an.
- Ebenen lassen sich direkt im Editor umbenennen. Bildlayer haben eine
  einstellbare Deckkraft. Die Aktion „Anker glätten“ richtet die Griffe des
  gewählten Bézierankers aus.
- Das Menüleistenmenü ist kompakter. Die Einstellungen bündeln Anmeldestart,
  Updates, Oberflächengröße, Mediathek und Wiedergabe.
- Ziehe Dateien zum Import an eine beliebige Stelle in der
  Hintergrundbild-Mediathek. Mit der Eingabetaste benennst du das ausgewählte
  Hintergrundbild um.
- Wupsy bereitet geeignete Bild- und Szenenwechsel vor und behält bei einem
  Vorbereitungsfehler den bisherigen Hintergrund bei.

Die Ausgabe ist für Apple silicon (ARM64) vorgesehen und hat macOS 14 als
Mindestziel. Die Musiknoten-Anleitung erklärt die neuen Editor-Funktionen
an Beispielen. [Musiknoten-Anleitung](../anleitungen/MUSIKNOTEN.md)
