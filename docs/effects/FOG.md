# Fog

Fog is a standalone native layer. Position it between images in painter order to
veil the background and preserve foreground occlusion. Its premultiplied output
uses source-over in the existing composition pass. The Fog menu adds a layer
with these defaults and activates mask editing with a black full-canvas mask.

| Setting | Range | Default |
|---|---:|---:|
| Density | 0…1 | 0.23 |
| Softness | 0…1 | 0.90 |
| Horizontal drift | −128…128 | 4 |
| Vertical drift | −128…128 | −0.5 |
| Structure scale | 32…8192 | 2200 |
| Height | 0.05…1.5 | 1.5 |

Drift uses logical canvas units per second, positive right and down. The
inspector's eight arrows preserve speed within the stored per-axis limits.
Choosing an arrow from rest starts at 9 logical units per second. The speed slider
scales the drift vector and gives fine control at low speeds. Its limit depends
on the direction and the existing per-axis bounds. The numeric speed field
scales the same vector within that limit. Editing X or Y updates the speed,
which is the magnitude of the drift vector. At zero,
the editor remembers the last direction for that layer during the current session.
If none is known, increasing the speed starts motion to the right.

The thumb and its numeric readout update locally during dragging. The editable
speed and X/Y fields reflect the final values on release. Live Preview
can skip intermediate values and draws the latest available drift using prepared
resources. Releasing the slider adopts the final X/Y values as a single Undo step.
WSS stores the drift components. The derived speed and remembered direction
belong to the editor session.

Structure scale is in logical units per primary tile. Height is measured from the
bottom as a fraction of canvas height. Values above one extend the fade above the
canvas. Softness reduces structure contrast and lengthens the vertical fade.
The native color well edits SDR sRGB with no alpha channel. The default is
RGB (0.94, 0.95, 0.96). Density controls opacity, including for dark colors.

Fog uses two differently transformed samples of a shared periodic 128×128 R8
tile generated by the existing WSS Clouds noise generator. The fields drift at
different rates, with the time phases reduced independently. One draw per visible,
nonzero-density layer with mask coverage covers at most its visible region.
A hidden layer, zero density, an entirely black mask or two zero drift
components does not request animation.
In the editing canvas, the fog mask tint follows the same vertical
envelope as the effect. The tint ignores the animated noise and drift. The
full-canvas frame and mask coordinates stay fixed as height changes.
A missing mask uses a virtual white sample for the tint until a stroke changes
coverage. Removing a mask or undoing its creation restores that view.

The optional scalar mask uses top-left UV across the entire logical canvas.
The existing fog draw samples the R8 texture with linear clamped filtering
and applies the sample to alpha before premultiplication. Height continues
to control where fog can appear. A missing mask or white coverage gives full
effect strength. Black hides the effect and gray scales its alpha. Fully black
masks are validated without render texture upload and contribute no fog draw.

The version 1 layer object accepts `type`, `visible` (defaults to true),
optional `mask` and the required `fog` object. The decoder also accepts the
legacy `preset` values `ground` and `atmosphere` from Wupsy 0.7.0. They have
no effect on the model or rendering and are omitted on the next save.
The mask uses the [explicit scalar asset contract](../../WSS-SCENE-FORMAT.md#clouds-and-mask).
Older Wupsy versions reject fog objects containing the new field. Existing
unmasked projects load without migration. All keys in the following `fog` object are required:

```json
{
  "type": "fog",
  "visible": true,
  "fog": {
    "density": 0.48,
    "softness": 0.75,
    "driftX": 9,
    "driftY": 0,
    "scale": 1500,
    "height": 0.38,
    "color": {"red": 0.94, "green": 0.95, "blue": 0.96}
  }
}
```

All numeric parameters are finite. Unknown keys fail validation. Reset to
Defaults restores the values above and preserves the mask, visibility and order.
