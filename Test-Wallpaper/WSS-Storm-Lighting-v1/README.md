# Native Storm Lighting 4K fixture

Original synthetic Wupsy fixture, covered by the repository LICENSE. No downloaded
assets or personal image data. The schematic foreground person and background are
generated by scripts/generate-wss-storm-lighting-fixture.py with Python stdlib only.
Run that script with --check to verify generated PNGs and manifest without writes.

Import this directory or scene.wss.json. The 3840×2160 background contains dark
checker detail, a bright checker patch and eight grey steps (0…240). Storm sits
between that image and a transparent foreground image. The figure must occlude
bolt geometry while both the figure and background brighten during the impulse.

Defaults: two flashes every three seconds, 0.16-s pulse duration, 2 EV and 0.025
shadow lift, slightly blue light. Use the two independent inspector switches to
check bolt only, illumination only, both and both off. Set shadow lift to zero to
check that pure black remains black. Check detail in the bright patch rather than
expecting unchanged contrast at strong exposures.

Manual checks: 24/30/60 FPS, Standard/HiDPI and 4K; pause at an impulse and resume;
change bolt and light colors independently; Save/Reopen; Undo/Redo; hide Storm;
overlap several Storm lights; disable lighting and confirm original appearance.
The first frame/thumbnail at time zero is intentionally dark before the first event.
