# WSS Rain v1 — Night study

Import this directory using Wupsy's **Add wallpaper**, then select it. Native
WSS playback is automatic. No terminal, external textures or engine installation
is needed. Covered by Wupsy's repository LICENSE.

1920×1080 logical canvas. Ordered layers: opaque night-gradient background, native
Rain, transparent foreground. Rain must disappear behind both pillars and the
horizontal rail, while remaining visible through the central opening.

Exact rain parameters: direction 0° (down), speed 900 logical units/s, density
100 drops per million logical square units, length 32, full width 1.2, opacity
0.08…0.24, seed 1, sourceOver. Nominal population: 207; additional padded-domain
instances maintain coverage at the region edges. Eight depth groups vary reference length, width and speed by 0.69375…1.30625; separate 0.5/1/1.5 length classes additionally vary length. A filled population is visible at t=0.

Both PNGs are original procedural geometry/colors generated by
`scripts/generate-wss-rain-fixture.py` using only Python's standard library. No
reference, Wallpaper Engine, downloaded, photographic or third-party assets.
The foreground has fully transparent pixels outside its three opaque shapes.

Compare Standard/HiDPI, 30/60 FPS and pause/resume. Logical amount and motion must
remain the same when raster density changes. FPS changes retain Wupsy's existing
restart policy. Judge rain appearance manually; no engine pixel-equivalence claim.
