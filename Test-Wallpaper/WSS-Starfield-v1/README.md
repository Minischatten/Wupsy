# Native Starfield v1 acceptance scene

Original synthetic Wupsy scene and schematic foreground, repository LICENSE.
Generated by `scripts/generate-wss-starfield-fixture.py`; `--check` verifies exact
reproducibility without writes. No personal photos or third-party assets.

Import this directory or scene.wss.json. A 4K black canvas holds 3000 static stars
behind a transparent foreground silhouette. No extra mask or background image.
The small synthetic PNG is deliberately scaled; it is an occlusion check, not art.

Manual acceptance:
- Select Starfield; move and independently resize its frame. No rotation handle.
- Inspect stars and foreground occlusion in Live Preview and desktop playback.
- Try white, red, green, turquoise and violet; compare variation 0 and 1.
- Enable gentle twinkling; inspect independent phases at 24/30/60 FPS.
- Set drift X/Y to positive and negative values; inspect all four region edges.
- Disable twinkling and set both drift speeds to zero for a static sky.
- Save/Reopen, Undo/Redo, hide/show and reorder the layer; try multiple Starfields.
- Compare Standard/HiDPI and 4K. All halos must remain within the rectangle.

The editing canvas intentionally shows images and the position frame; stars are
rendered in Live Preview. This fixture does not access or include Jadyn's image.
