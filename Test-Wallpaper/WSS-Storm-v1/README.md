# Native Storm fixture

Original synthetic Wupsy fixture, authored for this implementation. No third-party
assets or generator code. All pixels are generated by Wupsy's native renderer;
there are no image resources. Uses the repository license.

Import this directory or its scene.wss.json. A blue-white branched bolt appears
roughly 0.4–0.8 seconds after start, flashes twice, and repeats every four seconds.
The background stays dark: global illumination is intentionally absent.

Check 24/30/60 fps, Standard/HiDPI, pause/resume, seed changes, zero branch depth,
zero glow, rename, save/reopen, Undo/Redo and foreground-image occlusion. Numeric
position/direction controls and Canvas handles are available. Selecting Storm shows
a stable frame; drag to move, use corners to scale (Shift: independent), and the
round handle to rotate. Check the native color picker and smooth segment joins.
