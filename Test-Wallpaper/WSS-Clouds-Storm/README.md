# Native WSS Clouds Storm

Import this folder in Wupsy. Own procedural dark gradient/horizon and red mask,
generated by `scripts/generate-wss-clouds-storm-fixture.py` from authored colors
and geometry using only the Python standard library. No input images, engine
assets or downloads. Repository LICENSE; assets deliberately share our v2 design.

1920×1080; primary velocity [18,-2], scale 2800; secondary [-12,8], scale 5000;
influence 0.4; softness 0.9; density 0.55, intensity 0.65, brightness 1, shading
0.6 at 45°, seed 17. Broad diffuse masses retain internal variation.
Compare against the unchanged Clouds-v2 fixture: same general native effect,
with reduced fine structure and broader transitions here. Velocity, scale, intensity, density and brightness are editable in the native editor; softness and shading remain document-level settings.
