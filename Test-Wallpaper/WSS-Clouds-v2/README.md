# WSS Clouds v2 — Night fields

Import this folder with Wupsy's **Add wallpaper**. Native WSS playback is automatic.
No Wallpaper Engine installation, shaders, noise or runtime resource is needed.

1920×1080 canvas, a dark own night gradient with a quiet geometric horizon, and an
own scalar mask fading from full sky effect to no effect at the bottom. Both PNGs
are generated by `scripts/generate-wss-clouds-v2-fixture.py` using Python's standard
library, authored colors/geometry and no input images/downloads. Repository LICENSE.

Exact parameters: Primary velocity [18,-2], scale 1600; Secondary velocity [-12,8],
scale 700, influence 0.4; intensity 0.65, density 0.55, brightness 1, shading amount
0.6, shading direction 45°, seed 17. Mask: assets/mask.png. Image composition replace.
Velocity is local top-left image units/s (right/down positive); shading 0° is up,
90° right. Scales are logical units per repeated native noise tile, not engine scales.

Primary creates larger connected masses. Secondary adds smaller structure moving
in a different direction. Directional tone variation supplies a bounded depth cue;
it is not physical lighting or engine-equivalent shading. Brightness multiplies
cloud tone, not coverage. Compare Standard/HiDPI, FPS and pause/resume. The masked
horizon should retain the background. Final visual acceptance belongs to the user.

The existing WSS-Clouds-v1 fixture and its generator remain unchanged.
