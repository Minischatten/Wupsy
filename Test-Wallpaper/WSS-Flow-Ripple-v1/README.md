# WSS Flow → Ripple v1 — side by side

Own synthetic fixture under the repository MIT license; generated without input
media, external fonts, W1 maps, engine textures, shaders or bytecode.

Left: Flow. Right: the same image/map/logical size/Flow settings and time, followed
by native Ripple. The independently authored ripple adds local surface motion
without changing the Flow data. Both panels use curved vectors and feathered
coverage. Labels belong to a static backdrop and remain untouched.

Import the folder into Wupsy. Compare local transport and the additional ripple
in motion, including Standard/HiDPI and Pause/Resume. The inverse order is also supported and generally produces different output; this fixture demonstrates Flow followed by Ripple.
Generator: `scripts/generate-wss-flow-fixture.py` (`--check` is read-only).
