# WSS Flow v1 — directions, magnitude and coverage

Entirely original synthetic pixels, maps and bitmap lettering generated by
`scripts/generate-wss-flow-fixture.py`; repository MIT license. No photos, fonts,
Wallpaper Engine/W1 data, normal/phase assets, DXBC or external resources.

Import this folder into Wupsy and use native WSS playback. Labels remain still;
textured interiors show right, left, down, up, diagonal and curved local flow.
The 0.25 / 0.5 / 1 row varies vector magnitude; SOFT EDGE varies magnitude at the
boundary; COVERAGE varies alpha independently. NEUTRAL is an exact no-flow control.
The canvas is 1920×1080 logical units; the image/map are 960×540 texels.

Compare directed movement, seams, pulsing contrast, ghosting and sharpness over
multiple cycles. Crossfading finite source samples can soften or duplicate detail;
this is image distortion, not physical fluid simulation or unlimited transport.

See the companion `WSS-Flow-Ripple-v1` for a side-by-side chain comparison.
Regenerate with `python3 scripts/generate-wss-flow-fixture.py`, or pass `--check`
to verify every generated PNG/document without writes.
